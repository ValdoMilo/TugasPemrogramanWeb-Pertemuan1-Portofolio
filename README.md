Portofolio Pribadi - Tugas Pemrograman Web (Pertemuan 1)

Repository ini berisi source code untuk tugas mata kuliah Pemrograman Web pada pertemuan pertama. Proyek ini merupakan sebuah website portofolio statis sederhana yang dibangun untuk mendemonstrasikan pemahaman dasar mengenai pembuatan struktur halaman web dan desain visual.

📝 Deskripsi Proyek

Proyek ini adalah halaman web portofolio pribadi yang bertujuan untuk memperkenalkan diri secara profesional di internet. Website ini mencakup beberapa bagian dasar seperti profil singkat, riwayat pendidikan, daftar keahlian (skills), dan informasi kontak. Proyek ini menjadi fondasi awal dalam mempelajari pengembangan web front-end.

✨ Fitur

Beranda (Hero Section): Menampilkan nama lengkap, peran, dan foto profil.

Tentang Saya (About Me): Deskripsi singkat mengenai latar belakang dan minat.

Keahlian (Skills): Menampilkan daftar kemampuan atau teknologi yang dikuasai.

Kontak (Contact): Tautan ke media sosial atau email untuk kemudahan komunikasi.

🛠️ Teknologi yang Digunakan

HTML5: Digunakan untuk membangun kerangka dan struktur utama dari halaman web.

CSS3: Digunakan untuk mengatur tata letak, warna, tipografi, dan gaya visual halaman agar lebih menarik.

🚀 Cara Menjalankan Proyek (Instalasi)

Karena proyek ini adalah website statis murni, Anda tidak memerlukan instalasi server khusus (seperti Node.js atau Apache) untuk menjalankannya.

Silakan clone repository ini ke komputer lokal Anda menggunakan Git:

git clone https://github.com/ValdoMilo/TugasPemrogramanWeb-Pertemuan1-Portofolio.git


Buka folder hasil clone tersebut di perangkat Anda.

Cari file utama (biasanya bernama index.html).

Klik dua kali (atau drag and drop) file index.html tersebut ke dalam browser web Anda (seperti Google Chrome, Mozilla Firefox, atau Microsoft Edge).
